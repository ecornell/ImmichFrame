# 📦 ImmichFrame Release v1.0.37.1 – October 19, 2026

This release adds a web settings editor, makes repeats much rarer with a persistent shown-photo history, lets native frames play videos, moves to .NET 10, and fixes a long list of reliability and security problems.

---

## What's Changed

### ⚠️ Breaking Changes

#### 💥 Runs on .NET 10
**Commit [9a49ec5](https://github.com/ecornell/ImmichFrame/commit/9a49ec5) by @ecornell**

ImmichFrame now targets .NET 10, because .NET 8 leaves support on November 10, 2026. Docker images are unaffected apart from a newer base image (`aspnet:10.0-noble`). If you run ImmichFrame directly from source or a published build, install the .NET 10 runtime first.

---

#### 🔐 The settings API no longer accepts arbitrary API key file paths
**Commit [dab6c93](https://github.com/ecornell/ImmichFrame/commit/dab6c93) by @ecornell**

The settings API could previously be told to read any file on the server as an account's API key and send it to any server. An account can now only keep the `ApiKeyFile` it already has, on the same server. If you set up file-based keys, edit `Settings.json` (or your YAML or environment variables) directly rather than through the API.

---

### ✨ New Features

#### ⚙️ Web settings editor
**Commit [236d223](https://github.com/ecornell/ImmichFrame/commit/236d223) by @ecornell**

You can now manage ImmichFrame's settings and accounts from a browser at `/settings`, with no file editing or container restart. Running frames check for changes every five minutes and reload themselves when the settings change ([ec9addd](https://github.com/ecornell/ImmichFrame/commit/ec9addd)). Set `AuthenticationSecret` if anyone you don't trust can reach your frame server, because otherwise anyone who can reach it can read and change the settings.

```yaml
General:
  AuthenticationSecret: "choose-a-long-random-value"
```

---

#### 🔁 Far fewer repeats
**Commit [cf4d210](https://github.com/ecornell/ImmichFrame/commit/cf4d210) by @ecornell**

ImmichFrame now picks from the least recently shown quarter of your photos, using one history shared by every client. The history is saved to `ShownAssets.json` in your config folder, so restarts and settings changes no longer start the rotation over. Album selections are also cycled properly instead of favouring recent repeats ([e0fb3d3](https://github.com/ecornell/ImmichFrame/commit/e0fb3d3)).

---

#### 🎬 Videos for native frames
**Commits [59cfb8d](https://github.com/ecornell/ImmichFrame/commit/59cfb8d), [fcf1b29](https://github.com/ecornell/ImmichFrame/commit/fcf1b29) by @ecornell**

Native clients such as the Android app can now ask `RandomImageAndInfo` for videos as well as photos (`includeVideos=true`), and can skip the inline image to save CPU on low-power frames (`includeImage=false`). Existing clients are unaffected because both options default to the old behaviour. Videos play whatever Immich serves, so if they stutter on a slow frame, lower Immich's video transcoding target (for example 720p).

---

### ⚡ Fixes

#### 🐛 Frames recover from slow or dropped connections
**Commits [b454913](https://github.com/ecornell/ImmichFrame/commit/b454913), [5560555](https://github.com/ecornell/ImmichFrame/commit/5560555), [485079f](https://github.com/ecornell/ImmichFrame/commit/485079f) by @ecornell**

On a slow link, the frame used to restart a photo's download from scratch and could stay on "Offline — retrying" forever. Slow downloads now get to finish, and retries back off from 2 to 30 seconds. The slideshow also starts and recovers more reliably.

---

#### 🐛 Multi-account and filtered libraries
**Commits [f28b6c3](https://github.com/ecornell/ImmichFrame/commit/f28b6c3), [02598e4](https://github.com/ecornell/ImmichFrame/commit/02598e4), [6bff120](https://github.com/ecornell/ImmichFrame/commit/6bff120), [5cc8382](https://github.com/ecornell/ImmichFrame/commit/5cc8382) by @ecornell**

With several accounts, photos no longer fail to load after a restart or settings save, or when ImmichFrame first asks the wrong account for a photo. Excluded albums and other filters no longer cause occasional "no asset found" errors, and a video-heavy library no longer makes image-only clients fail.

---

#### 🐛 Settings editor fixes
**Commits [5a3a3b6](https://github.com/ecornell/ImmichFrame/commit/5a3a3b6), [7f6f475](https://github.com/ecornell/ImmichFrame/commit/7f6f475) by @ecornell**

Removing an account no longer moves its album or person IDs onto the next account. An invalid clock or date format (such as `YYYY`) now falls back to the default instead of breaking the clock and overlays.

---

#### 🐛 Webhooks and video streaming
**Commits [6ddfe46](https://github.com/ecornell/ImmichFrame/commit/6ddfe46), [1620ebf](https://github.com/ecornell/ImmichFrame/commit/1620ebf), [2bf8b3b](https://github.com/ecornell/ImmichFrame/commit/2bf8b3b) by @ecornell**

Webhooks now fire once per photo or video shown, instead of twice or on every retry. An unreachable webhook URL no longer leaks connections. When a player seeks or closes, ImmichFrame stops downloading that video from Immich instead of logging errors.

---

#### 🐛 Birthdays on the right day
**Commit [7fed968](https://github.com/ecornell/ImmichFrame/commit/7fed968) by @ecornell**

Birthday confetti fired a day early in time zones west of UTC, such as the Americas. It now fires on the right local day.

---

#### 🔒 Security hardening
**Commits [16cccfc](https://github.com/ecornell/ImmichFrame/commit/16cccfc), [c98173e](https://github.com/ecornell/ImmichFrame/commit/c98173e), [8692d28](https://github.com/ecornell/ImmichFrame/commit/8692d28) by @ecornell**

The settings editor no longer shows raw responses from other servers in its errors, which could have been used to read pages from hosts the server can reach. Stored credentials are no longer passed along to other servers. A local `Settings.json` and other secret files can no longer end up in a Docker image or in Git.

---

#### 🐛 Client identifier and URL check
**Commit [dd4f3ac](https://github.com/ecornell/ImmichFrame/commit/dd4f3ac) by Dominik Schmidt, commit [e973c01](https://github.com/ecornell/ImmichFrame/commit/e973c01) by @JW-CH**

Frames now send their client identifier with asset list and config requests, so per-device logs are complete. The server URL check moved to page load.
